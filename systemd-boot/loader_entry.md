## Loader Entry

The systemd-boot loader entries are located at:

```text
/efi/loader/entries/
```

Edit both the normal and fallback `.conf` files in this directory.

Append `acpi_backlight=native` as the last parameter of the `options` line.

Example:

```ini
options <existing-kernel-parameters> acpi_backlight=native
```

### Notes

- Preserve all existing kernel parameters.
- Append the parameter to the existing `options` line, not as a separate line.
- Apply the change to both normal and fallback boot entries.

Also keep `acpi_backlight=native` in `/etc/kernel/cmdline` so future boot entries generated by `kernel-install` inherit the parameter.

After editing, reboot and verify:

```bash
cat /proc/cmdline
```

Confirm that `acpi_backlight=native` appears in the output.
